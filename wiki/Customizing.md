# Customizing

Fork-friendly knobs:

| Want to change… | Edit |
|-----------------|------|
| Starting resources, building costs, fail math | `src/lib/gameConfig.ts` |
| Streaks, research costs, achievements | `src/lib/meta.ts` |
| Ambient events | `src/lib/events.ts` |
| Crew roles / slot curve | `src/lib/crew.ts` |
| Sounds | `src/lib/audio.ts` |
| 3D look / perf | `src/components/Scene.tsx`, `src/lib/perf.ts` |
| Brand logo | `public/brand/` |

Full map: [`docs/CUSTOMIZING.md`](https://github.com/ArdaDDemir/floating-observatory/blob/master/docs/CUSTOMIZING.md)
